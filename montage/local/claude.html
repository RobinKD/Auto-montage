Se connecter avec votre compte Claude

  1. Elle s'ouvre dans un nouvel onglet de ce navigateur, sur claude.com. Même si vous êtes déjà connecté à claude.ai, ce site peut vous demander de vous connecter une fois (pour le navigateur, claude.com et claude.ai sont deux sites différents) : utilisez le même compte et la même méthode (Google, e-mail…). Cliquez ensuite sur Autoriser. Un abonnement Claude (Pro ou Max) est nécessaire.

    Une fenêtre du navigateur à propos de la « synthèse vocale » peut apparaître sur cette page de claude.com : elle ne vient pas d'Auto-montage et n'empêche pas la connexion, vous pouvez la fermer.

    L'onglet ne s'est pas ouvert ? Ouvrir la page d'autorisation

  2. Après l'autorisation, la page affiche un code : copiez-le et collez-le ici.

Auto-montage ne peut pas lire les cookies de votre navigateur (aucun site ne le peut, pour votre sécurité) : c'est pour cela que l'autorisation passe par cette page, ouverte dans votre navigateur. Autre possibilité : le lanceur « Claude Code » (terminal), ou une clé d'API (variable ANTHROPIC_API_KEY avant de lancer Auto-montage).

Utiliser plutôt un compte Anthropic Console (facturation à l'usage de l'API)
